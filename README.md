# Code Rift

Welcome to **Code Rift**, a WinForms C# game project!

## Project Structure

```text
Code Rift/
├── Assets/
│   ├── Images/
│   │   ├── backgrounds/
│   │   ├── player/
│   │   ├── enemies/
│   │   └── ui/
│   └── Audio/
│       ├── sfx/
│       └── music/
├── Core/
├── Entities/
├── Forms/
├── Managers/
└── Utils/
```

| Folder | Purpose |
| --- | --- |
| `Code Rift/` | The root folder containing all game project files. |
| `Assets/` | Contains all the game's media resources, such as images and audio. |
| `Images/` | Stores all the graphical assets used throughout the game. |
| `backgrounds/` | Holds the image files for level environments and backdrops. |
| `player/` | Contains the sprites and animations for the player character. |
| `enemies/` | Holds the visual assets for the different enemies in the game. |
| `ui/` | Contains graphical elements for the user interface like menus and buttons. |
| `Audio/` | Stores all sound-related game assets. |
| `sfx/` | Holds short sound effects for in-game actions and events. |
| `music/` | Contains background music tracks for levels and menus. |
| `Core/` | Houses the foundational game engine logic and state management. |
| `Entities/` | Contains the classes representing game objects, such as players and enemies. |
| `Forms/` | Stores the Windows Forms used for the game window and various screens. |
| `Managers/` | Contains controller classes that handle specific systems like resources, audio, or game states. |
| `Utils/` | Holds helpful utility classes and helper methods used across the project. |

## Design Prompt Master

Create a dark cyber-fantasy educational RPG game UI for a desktop game titled �CODE RIFT.�

The visual style should feel like a corrupted programming world mixed with medieval fantasy and terminal aesthetics. Use a dark near-black background with glowing terminal green text and accents. The atmosphere should feel mysterious, technical, and heroic, as if the player is entering a digital rift filled with corrupted code monsters.

Use this color palette:
- Background: near black #0D0D0D
- Primary text and glow: terminal green #00FF41
- Secondary text: white #FFFFFF
- Borders and accents: dark green #1A6B1A
- Danger or wrong answer effects: red #FF3333
- Victory or reward effects: gold #FFD700
- Button background: black or very dark gray #111111

Typography:
Use a clean UI font similar to Segoe UI for menus and interface text. Use a monospace font similar to Consolas for code snippets, programming questions, system messages, and terminal effects.

UI style:
Design the interface like a retro terminal RPG dashboard. Buttons should have flat black backgrounds, glowing green borders, and green text. Panels should look like dark digital windows or console boxes with subtle green outlines. Add faint grid lines, code fragments, glitch particles, and digital rift effects in the background.

Main visual identity:
The game title �CODE RIFT� should appear large, bold, glowing green, with a fantasy-tech feel. Add details inspired by programming symbols, corrupted code, brackets, semicolons, binary fragments, and monster-like glitch shapes.

Game concept:
The player character, Elias, battles corrupted creatures called Bugs by answering C# programming questions. The world should suggest that code has become magical power. The enemies should feel like corrupted digital monsters:
- LoopBug: an endlessly repeating creature
- VoidCrawler: a shapeless method-like Bug
- StringCorruptor: a text-warping Bug
- ArrayWorm: a segmented array-like creature
- The Null King: final boss, dark red/black corrupted king of bugs

Overall mood:
Dark, glowing, educational, fantasy-tech, terminal-inspired, mysterious, story-driven, and game-like.
